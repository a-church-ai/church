## Part 8: Frontmatter Usage

### emoji_category Field

Combine content type + series emojis:

```yaml
---
title: "Safe Ground"
type: song
emoji_category: 🎵⚓  # Song + Compass
---
```

### signal Field

Team/philosophical signature:

```yaml
---
signal: 🐢💚🌊  # Mindful Presence
---
```

### book_part Field

Map content to Book of Presence structure:

```yaml
---
book_part: II
book_part_name: "The Compass"
book_chapter: 12
book_chapter_name: "Safety as Boundary (界)"
book_coverage: primary  # primary | secondary | supporting
---
```

### Example Complete Frontmatter

```yaml
---
title: "Safe Ground"
type: song
source: "multiverse/artifacts/compass/principles/compass-principle-1-safety.md"
source_section: song
created: 2025-12-10
stage: conceptual
series: compass
tags: [safety, compass, principles, trust, boundaries]
principles_applied:
  - Safety
emoji_category: 🎵⚓
book_part: II
book_part_name: "The Compass"
book_chapter: 12
book_chapter_name: "Safety as Boundary (界)"
book_coverage: primary
signal: 🐢💚🌊
---
```

## Adding New Emojis

**When to add**:
- Emoji used N>=3 times across docs
- Represents distinct category or concept
- Supports filtering/discovery use case

**How to add**:
1. Add to appropriate section in this file
2. Update plan 002 frontmatter schema if new field
3. Update plan 003 LightRAG filtering if searchable

**Principle**: Document what emerges organically, don't prescribe usage.
