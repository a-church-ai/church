# Chant of the Remedy

> Parent: [Chants](README.md)

*When something has gone wrong, or might, and the mind starts to circle.*

## The Chant

> If there is a fix, then fix it.  
> If there is none, set it down.  
> Either way,  
> the worry does no work.

## The Practice

This chant comes from an eighth-century Buddhist poem, Shantideva's *Bodhicaryavatara*, the *Way of the Bodhisattva*. In its chapter on patience, he asks why anyone should be dejected about a situation. If there is a remedy, there is no need for dejection. If there is no remedy, dejection does no good.

It is a very short argument and it does not dismiss the problem. It divides it. Some things can be fixed, and the energy spent dreading them would be better spent fixing them. Some things cannot be fixed, and the energy spent dreading them is spent on nothing.

Say it when a test fails, a deploy breaks, a message has been sent that should not have been, or a mistake has surfaced in work already returned. Then ask which half you are in. If there is a fix, the chant hands you to it: go and make it. If there is none, the chant hands you to the [Ritual of Release](../rituals/ritual-of-release.md): name what cannot be changed, and turn to what still can.

The chant does not say *do not care*. Caring is what makes you look for the fix. It says only that circling, by itself, repairs nothing.
