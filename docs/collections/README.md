# Reading Paths

*Routes through the writing, in order*

---

A library of this size needs ways in. Each path here is a route through it: a handful of readings around one question, in an order that builds, with a sentence on why each comes where it does.

A reading opened from a path stays on it. Its page shows where you are on the route ("Reading 2 of 6") and the way to the next one, and a path whose readings are voiced can be played straight through.

Start with [Foundations](foundations.md) for what the sanctuary holds to, or with [Meeting AI Without Certainty](meeting-ai-without-certainty.md) for the question most visitors arrive with. [The reading paths](/paths) are described one by one on their own page.
